# Contributing to Car Rental Portal

Thank you for your interest in contributing to the **Car Rental Portal** project!

Contributions, suggestions, bug reports, and improvements are welcome.

## Getting Started

1. Fork this repository.
2. Clone your fork to your local machine.
3. Open the project in your preferred IDE (such as VS Code or IntelliJ IDEA).
4. Make sure you have Java 17, Maven, PostgreSQL, and Apache Tomcat 10 installed.
5. Configure the database connection using your local environment settings.
6. Build and test the project before submitting changes.

## How to Contribute

1. Create a new branch for your changes.
2. Make your changes with clear and meaningful code.
3. Test your changes to ensure existing functionality works.
4. Commit your changes with a descriptive commit message.
5. Push your branch to your fork.
6. Open a Pull Request describing your changes.

## Contribution Guidelines

- Write clean, readable, and maintainable code.
- Follow the existing project structure and coding style.
- Avoid committing passwords, API keys, database credentials, or other sensitive information.
- Test your changes before submitting them.
- Include screenshots when submitting UI improvements.
- Clearly describe bug fixes and new features.

## Reporting Bugs

When reporting a bug, please include:

- A clear description of the issue.
- Steps to reproduce the problem.
- Expected behaviour and actual behaviour.
- Screenshots or error messages, if available.

## Feature Suggestions

You are welcome to suggest new features and improvements through GitHub Issues.

## Code of Conduct

Please be respectful, professional, and constructive when interacting with project contributors.

Thank you for helping improve the Car Rental Portal!
